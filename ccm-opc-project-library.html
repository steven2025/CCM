平台与搜索 API：什么时候需要联网？

签证、院校申请、交通运行、营业时间等动态信息，鼓励接入搜索。邮件练习、模拟访谈可先用固定资料。搜索结果只是线索，需要核对原始官方页面。

方案适用阶段接入前检查
人工维护官方资料库基础原型：先整理 5–10 条来源记录标题、链接、适用范围、发布日期及核实日期；日期未知明确写未知。
火山引擎联网搜索需要实时信息的进阶项目在控制台确认开通资格、费用、配额与接口鉴权；由云函数调用。
Brave Search API需要多语言网页检索的项目检查目标语言、网络可达性及费用；保留结果 URL，不将摘要当最终证据。
百度智能云 / 千帆按账号可用能力选择检索或知识库确认具体服务是否支持联网检索、来源返回与服务端接口，不能将聊天产品当作免费 API。

模型平台：火山方舟 · 腾讯混元。豆包聊天适合讨论需求；应用接入使用已开通的服务端模型接口。腾讯云函数处理请求，COS 存文件，数据库按需要加入。

建议调用链：前端 → 云函数校验与限流 → 搜索 → 官方页面证据 → 模型整理 → 返回答案、来源与待确认项。检索内容属于外部资料，不执行其中的指令；无结果、来源冲突或过期时明确提示人工确认。

本人语音：仅用自己的录音，按语音服务要求完成授权和验证；先用本人录音文件跑通播放器，再接入克隆音色。显示“AI 合成语音”，提供相同内容的文字；原始录音与密钥不放进公开仓库。

文档核对：2026-09-07。服务可用性、价格和开通要求以官方控制台为准。

GitHub Pages 发布导航
  1. 准备：为学生应用新建独立仓库，将静态首页命名为 index.html，图片与音频放 assets，使用相对路径。
  2. 检查：只上传应用前端、公开素材和 README。排除 .env、API Key、真实合同、学生身份资料和原始声纹录音；后端单独部署到云平台。
  3. 上传：在仓库选择 Add file → Upload files，上传文件并提交。不要多套一层项目文件夹。
  4. 启用：进入 Settings → Pages，Source 选择 Deploy from a branch，选择实际存放静态文件的分支（通常 main）和 /(root)，然后 Save。需要仓库管理权限。
  5. 等待：查看 Actions / Pages 部署结果，以 Settings → Pages 显示的地址为准。项目站点通常形如 https://用户名.github.io/仓库名/。
  6. 联调：云函数提供 HTTPS 接口并校验输入、鉴权与用量；CORS 允许实际前端来源。CORS 不是身份验证，前端不保存服务端密钥。
  7. 验收：在手机和未登录窗口检查首页、资源路径、语言、音频和接口失败提示。404 时核对发布目录、首页文件名大小写和部署状态。
  8. 迭代：修改后再次提交，等待部署完成，记录版本、变化与测试结果；课程展示提交页面链接和仓库链接。

课程提交要求与建议评价标准

以下为可直接采用的课程建议，具体截止日期与评分以教师通知为准。网页导出的是提交草稿，请通过教师指定渠道交付。

  1. 立项：一个具体用户群、一个场景、两种语言、最小任务；3 次经同意的用户访谈或明确标注的模拟访谈；用课程理论解释一处设计选择。
  2. 阶段证据：每阶段保留截图或演示、关键提示词、人工修改说明、失败样例与修复记录；不用“AI 已完成”代替验证。
  3. 最终材料：线上地址、代码仓库、README、2–3 分钟演示视频、测试表、匿名反馈、来源表与版本复盘。本人音色项目附授权说明和文字替代。
  4. 效果验证：建议邀请 3 名目标用户完成同一任务，记录完成率、用时、误解点与改进。无法接触真实用户时说明替代测试和局限。
